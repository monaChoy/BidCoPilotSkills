# 标书评分

评分基准只能来自完整招标文件评标办法及其有效澄清文件。spec、通用模板和经验权重不能替代评分基准。

两种模式：**快速**核对评标办法与现有响应结构的覆盖，写正文前即可运行；**完整**以投标文件正文为评分对象。其他技能产出的目录、spec均只作可选导航，不能仅凭它们判定正文覆盖。

## 1. 选择调用分支

- **直接调用**：读取项目 `AGENTS.md`；不存在或文件登记已变化时，先使用 `招标项目建档` 新建或更新。然后询问用户选择模式：
  1. **快速**：响应结构完整性核对。需要完整招标文件；优先使用已有 `标书目录.md`，没有时使用用户提供的章节提纲或投标文件现有目录/标题。若尚无任何响应结构，仍提取评分基准并交付“待安排响应位置”清单，不要求先使用 `标书目录整理`。
  2. **完整**：评分检查或模拟评分。需要完整招标文件和完整投标文件；`标书目录.md` 存在时作为定位导航。确认文件后询问是否需要模拟评分；用户未选择模拟时执行评分检查。
- **由标书检查流程调用**：直接执行完整模式的评分检查，不询问、不预测分数，把结果返回检查报告，不另写评分报告。

多份不同投标人的文件逐份独立评分，不做横向比较。

完成标准：调用分支、模式、目标文件和报告去向均已确定。

## 2. 建立评分基准

完整读取评标办法及有效澄清文件，逐项提取：评分项、满分、得分条件、所需材料、计算公式和来源锚点。同时从投标人须知、招标公告中提取评标办法之外的计分规则（如小微企业价格扣除、政策性加分），纳入评分基准并保留来源锚点。区分：

- 初步评审门槛：不是分值，交由标书检查判断；
- 客观评分项：可由明确材料、数量或状态直接判断；
- 主观评分项：依赖评委对方案质量的判断；
- 暂不可计算评分项：规则明确，但缺少其他投标人报价、现场随机参数或必要材料。

评分基准缺失或不可读时，停止模拟评分，列出缺失内容；仍可对已取得的评分项做评分检查，但不得补造通用规则或分值。

完成标准：每个评分项都有分值、得分条件和来源锚点，或已明确为缺失的评分基准。

## 3. 快速模式：响应结构完整性核对

逐项核对评分基准与当前可用的响应结构（`标书目录.md`、用户章节提纲或投标文件现有目录/标题）：

```text
评分项及满分
响应位置（章节标题；尚未安排时写“待安排”）
判断：已覆盖 / 缺失 / 分值不一致 / 待安排
```

- 有响应结构时，每个评分项应有唯一位置；结构中标注分值时核对其与评标办法是否一致。门槛条款只核对是否有响应章节，不核分值。
- 响应结构中带分值但无法对应评分基准的标题，核对是否来自澄清文件；无法对应的列为疑问。
- 没有响应结构时，不虚构“已覆盖”结论，逐项输出得分条件、所需材料和“待安排”状态，供后续直接撰写或整理结构使用。
- 结果直接交付用户；本技能不强制创建或改写 `标书目录.md`。
- 快速模式不核对正文证据、不预测分数、不写评分报告。

完成标准：每个评分项都有覆盖判断或“待安排”状态及其依据；所有缺失、分值不一致和多余带分值标题均已列出。

## 4. 评分检查（完整模式）

逐项核对投标文件：

```text
评分项及满分
得分条件
投标响应位置和证据
判断：满足 / 部分满足 / 未发现 / 待人工核实
评分风险
改进建议
```

有章节标题但没有满足具体得分条件或必要证据时，判断为“部分满足”，不能仅凭目录判定覆盖。材料不可见时使用“待人工核实”，不判零分。

流程调用时把“部分满足、未发现、待人工核实”的项目作为评分发现返回 `标书检查`，不生成预测分。

完成标准：全部评分项逐项有判断和投标证据，分值合计与招标文件一致；不一致时先报告评分基准问题。

## 5. 模拟评分（完整模式）

仅在用户直接调用完整模式并明确选择后执行：

- 客观评分项：证据充分且规则可直接计算时给出明确预计分；证据不足时给出条件式结果。
- 主观评分项：依据评分档位给预计得分区间，说明上下限依据和不确定因素。
- 报价等暂不可计算评分项：保留公式和所缺外部数据，不计为零分。

每项输出：

```text
评分项及满分
得分条件
投标响应位置和证据
判断
预计得分或得分区间
失分原因
不确定因素
改进建议
```

最后分别汇总客观预计分、主观预计分区间、暂不可计算分值和可计算范围内的总分区间；不得把暂不可计算分值混入确定总分。

完成标准：每个可评分项目都有可复核的计算或区间依据；每个不可计算项目都列明所缺数据。

## 6. 直接调用的报告

完整模式直接调用时写入 `投标输出/<项目名>/标书评分报告.md`：

```markdown
# <项目名> 标书评分报告

## 评分基准与范围
## 逐项评分
### S-001 <评分项>
<评分检查或模拟评分字段>

## 分值汇总
## 暂不可计算项
## 结论与边界
```

报告明确说明这是基于当前材料的辅助评估，不代表评标委员会实际得分。

完成标准：报告覆盖全部评分项、明确不可计算项，并已保存和向用户摘要交付。
