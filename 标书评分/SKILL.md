# 标书评分

招标文件及有效澄清是评分依据。目录、spec仅作导航，不能替代正文证据。缺少正式规则时不补造分值。

## 1. 确定分支

- 直接调用先读项目 `AGENTS.md`，缺少则建档；仅来源或确认素材变化需要更新，新增生成产物不触发重建。按用户意图选择明确的分支，含混时一次询问：**结构核对**、**正文评分检查**或**模拟评分**。模拟须用户明确要求。
- 结构核对可在正文前执行；无目录或提纲仍提取规则，响应位置写“待安排”。正文检查可检查全套或明确的局部范围，局部结果不冒充全套。
- `bid-outline` 调用时执行基准提取与结构核对，复用其输入版本、范围、标题树和评分类 REQ；将结果及 REQ 映射返回目录，不另写评分报告，不触发模拟评分。
- `bid-review` 调用时执行基准提取与正文评分检查，复用其输入版本、范围和用户是否需要模拟评分的选择；选择需要时继续第5节，将结果返回检查报告的“模拟评分”小节，不另写报告。选择已明确不重复询问；未传选择时由检查方询问，未获同意只返回正文核对结果。
- 被目录或检查调用时沿用调用方传入的 REQ，不另建一套要求编号；独立调用使用自己的评分项编号。

## 2. 提取评分基准

按评标办法及有效澄清逐项提取评分项、满分、条件、材料、公式和来源；再查须知、公告中的其他计分规则。价格扣除是报价计算规则，不当作加分混入总分。门槛不是分值，结构核对仅安排位置，合规判断交由 `bid-review`。

区分客观项、主观项和缺外部数据而暂不可计算项。父子项保留关联，加总只用不重叠的计分层级；合计与招标不一致先核查基准，不自行改分。规则或附件缺失时可检查已取得部分，标明未知范围；不得给全套预测总分。

直接调用时，结果记录招标、澄清、投标等输入路径、版本/日期、大小和修改时间。同名文件变化需核对影响，旧判断不得自动复用。按评分组分批读相关原文和证据、保存结果；续接从已存进度和下一项恢复，不依赖长对话。

## 3. 结构核对

每项输出要求ID（有基线时）、评分条件、分值、主响应位置和关联资料位置、来源以及“已安排/缺失/待安排/标注分值不一致”。一个评分项可以由多处内容共同支持，不要求全部证据在唯一章节。

“已安排”仅代表结构有位置，不代表正文满足。结构中无法对应招标的分值标题列为疑问。直接交付；用户需要保存或续接时保存到评分报告，不强制改写目录。

## 4. 正文评分检查

先应用范围：排除项记“本次范围外”，不计为失分；范围内依赖未审材料记“待人工核实”。每个评分项，包括满足项，都保存：

`要求ID（有基线时）/编号｜评分项及满分｜得分条件与来源｜投标证据或已查范围｜满足/部分满足/未发现/待人工核实｜风险与建议`

疑似空章先用工具实测：以正文标题到下一个同级或更高标题为边界，排除目录、各级标题、页眉页脚、空白和纯占位词；保留真实表格内容，记录边界、排除规则及有效正文字符数。不能把标题中的设备名算作响应，也不能靠字符数多少判断质量。图片、扫描表、嵌入对象和引用附件另查；文本提取为零但非文本内容未核实时记待人工核实。

正文及相关非文本材料均可读、排除标题后为空，且本次纳入分册与关联附件其他位置均无实质响应时，判“未发现”，不判“部分满足”或仅因空章而待人工核实。只有实质响应未覆盖全部条件才判部分满足。先明确多分册分工，其他分册不在检查范围而有必要依赖时记待核；范围外章节不作缺陷。判断数值先辨认精确值、下限、上限、区间等关系，不以机械相等代替规则。

逐项覆盖本次范围并核对分值层级。返回检查方时保留正常项，异常项关联其问题记录；待核不当作已确认失分。

本分支只报告招标满分及满足状态，不输出预计分、分数区间或“确定归零”。可对缺口涉及的招标分值去重汇总，但必须标明不是预计失分。用户同意模拟评分时继续第5节，将预计得分与检查事实分栏或分节展示。

## 5. 模拟评分

仅在用户明确要求或询问后同意时，沿用正文检查证据：客观项可计算则给预计分；主观项按原文档位给区间和依据；证据不足给条件式结果；依赖其他报价或随机参数时保留公式与所缺数据，不计零分。

使用计算工具复核公式、上限和汇总；保留计分规则与输入。分别汇总客观预计分、主观区间、暂不可计算分值和可计算范围内区间，不把父子项、价格扣除或未知项重复加总。

## 6. 直接调用的报告

正文检查或模拟写入 `投标输出/<项目名>/标书评分报告-YYYYMMDD-HHmmss.md`，重名加后缀，不覆盖旧报告。包含输入版本/范围、评分基准、全量结果、当前进度及下一项、适用的分值汇总、盲区和结论；正文检查不强行填预测分。

输入未变的中断续查可更新同一未完成报告；输入改变则新建报告，标明旧结果中哪些已重新核实。报告说明本次完成范围及未知范围，这是辅助评估，不代表评委实际得分。
