# 文档痕迹检查

脚本负责提取、统计和确定性比较；执行者负责核对候选、说明覆盖和限制。脚本不作真实性、串标或招标符合性判断。

## 执行

1. 确认明确文件及不存在的新输出目录。首次使用、更新脚本或更换 Poppler 环境后运行：

   ```bash
   python3 -B scripts/selfcheck_documents.py
   ```

2. 运行统一 CLI：

   ```bash
   python3 -B scripts/inspect_documents.py <文件...> --output <新目录>
   ```

   新脚本只使用 Python 标准库和已有 Poppler；缺工具或格式不支持时保留失败状态，安装软件前另行取得明确同意。

3. 默认读取 `<输出目录>/summary.json`。候选字段被截断、比较组超过摘要上限、状态不是 `parsed` 或需核对原始值时，再读取 `manifest.json` 中对应文件，不加载无关正文和清单。
4. 将每个输入的状态及覆盖写入调用方报告。`complete` 只表示脚本声明范围内全部输入均已解析，不表示无痕迹或真实性通过；任一 `partial / error / unsupported` 均使进程返回非零，同时仍保存其他结果。
5. 多文件比较只使用用户明确提供且有权使用的文件。报告相同文件哈希、嵌入对象哈希和字段原值及其位置，不设重复率阈值，不把相同值直接解释为违规。

具体字段、工具及未覆盖范围见 [解析覆盖与判断边界](references/coverage.md)。解释 PDF、DOCX 或比较结果前必须读取该文件。

## 输出约定

- `manifest.json`：完整输入信息、属性、候选位置、工具命令、嵌入对象和全部比较组。
- `summary.json`：状态计数、非空关键属性、候选计数与有限位置、紧凑比较组；供模型默认读取。
- 标准输出只返回输出路径、输入数、状态计数和比较组数量。

输入保持只读，输出目录必须不存在。摘要有意省略普通正文和无关工程量清单；不得因摘要没有某内容就断言原文件没有该内容。
