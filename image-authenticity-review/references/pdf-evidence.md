# PDF 证据提取与覆盖核验

检查 PDF 时先执行本流程，再分析图片。元数据只能证明所读取字节中有什么，先确定这些字节来自哪里。

## 三种来源

| 来源 | 记录内容 | 可作的判断 |
| --- | --- | --- |
| 对象原始编码流 | PDF 哈希、对象号与代数、滤镜、引用页与资源路径、流哈希、工具版本 | 对已验证的独立 JPEG 读取原始流保留的元数据；不等于相机原片 |
| 解码像素 | 对象与流对应关系、颜色空间、位深、解码与遮罩处理 | 用于像素观察；解码结果通常不包含原始文件元数据 |
| 重编码或渲染副本 | 来源对象或页码、导出方法、格式与参数、输出哈希 | 用于展示、OCR 和定位；字段缺失不能反推原始流无记录 |

导出函数返回可打开的图片，不代表保留了原始字节。`page.images`、`image.data` 以及其他库的类似接口，按实际库版本和样本验证；不能一律认为保留或丢失元数据。哈希不同证明字节不同，不能单凭这一点确定改变的是哪些字段或像素。

## 可重复的最小流程

先检查已有 Python、Pillow、pypdf；下列脚本需要 Python 3.11 或以上。缺少依赖时说明内容与影响，取得明确同意后再安装。首次使用、升级库或换运行环境后，先从技能目录运行：

```bash
python -B scripts/selfcheck_pdf.py
python -B scripts/pdf_raw_images.py source/document.pdf output/new-extraction
```

自检只生成临时虚构 PDF，不联网、不读客户材料；验证已知 JPEG 字节和 Software 字段、同对象重复引用、嵌套 Form、未支持滤镜与内联图片、损坏流、阶段状态以及原件和已有输出保护。当前核验版本为 pypdf 6.10.0；其他版本以自检和实际能力为准，不强制安装该版本。

提取脚本读取页面内容中的图片绘制引用和嵌套 Form，一张图片对象只保存一次，保留每次引用位置。仅支持直接 `/DCTDecode` 或 `/DCT` JPEG；记录解析器原始编码缓冲区的哈希用于来源对应，将原字节写入独立 JPEG，再调用元数据整理脚本。提取方法是否保留已知 JPEG 字节由合成样本自检验证，不在每次写入后重复读回比较哈希。缓冲区是解析器提供的对象流字节，不是直接按磁盘偏移截取 PDF；脚本拒绝加密 PDF，不提供解密流程。元数据的工具覆盖限制仍然适用。

输出目录必须不存在，包含独立 JPEG 与 `manifest.json`。页面或对象失败不掩盖其他成功项；有失败、内联图或未支持滤镜时退出非零，但仍保存清单。零退出码仅代表脚本声明范围内的提取未报错，绝不表示完整鉴定或图片真实。

## 未覆盖项与后续处理

- **Flate、JPX、JBIG2、CCITT 及复合滤镜**：只登记对象、滤镜和可取得的流哈希，状态为未支持。不把裸像素流硬存为 JPEG，不因其无 EXIF 就认为没编辑过。按任务需要用已有适当工具进一步处理；没有处理完就列为未完成。
- **遮罩与显示变换**：记录 Mask、SMask、Decode 的存在；提取到 JPEG 不代表其独立显示与 PDF 页面完全一致。遮罩内部图片未遍历，位置、裁剪、旋转与实际画面另作页面核对。
- **内联图、批注外观、图案及未使用资源**：内联图遇到时列为未支持；其余不在本脚本扫描范围，清单 `not_covered` 明示。先判断目标文件是否涉及这些内容，需要覆盖时采用其他方法并补充记录。
- **私有 API**：原始缓冲区读取依赖 pypdf 的 `_data`。自检不通过、属性缺失或流不是独立 JPEG 时停止该提取方法，不静默改用可能重编码的导出接口再称作原始流。

每份 PDF 的实际覆盖范围还应考虑未调用的资源与页面外观。报告中的“全部图片”须与确认过的提取范围一致，不能把页面图片引用清单直接称作完整 PDF 对象取证。

## 检查深度与报告门槛

每张唯一源图记录对象与位置、来源类型、原始流哈希、提取方法及保真核验、元数据读取、缩略图初查、原尺寸局部复核、整页复核，以及每阶段的失败或未支持原因。脚本只自动登记、提取并读取支持对象的元数据，后三项默认未执行，由实际检查者附证据后更新检查清单；不要把脚本清单当作人工复核记录。

批量初查可看缩略图；合同、证照、签章及异常记录优先检查原尺寸关键文字和局部、再看完整页面。耗时或材料限制导致未完成时，明确已完成数量、对象或页码、剩余范围，以及哪些结论因此不能给出。原尺寸区域测量不等于已肉眼复核，整页渲染也不等于逐处检查。

报告只对完成相应证据核验的范围作结论。例如“已检查的原始 JPEG 流中检出软件记录”或“导出副本未返回字段，原始流未核验”；不能用后者推导“原文件无 Photoshop 记录”。原始 JPEG 中软件字段缺失也不证明未编辑。
