# BidCoPilotSkills

面向中国招投标场景的可复用标书技能库。项目把招标材料识别、标书设计、Markdown 初稿编制、独立检查和评分核对串成一条可交接的工作链。

## 技能链

```text
招标项目建档 → 标书spec → 标书撰写 → 标书检查
                                      ↘ 标书评分
```

- `招标项目建档`：盘点项目文件，经用户确认后建立或更新项目 `AGENTS.md`。
- `标书spec`：依据招标文件冻结标书设计纲要、决策依据和计划落点，不直接写正文。
- `标书撰写`：按已冻结的 spec 生成分章节 Markdown 初稿，并完成交接条件检查。
- `标书检查`：由独立检查上下文只读核查完整招标文件和投标文件，输出带双证据的 Markdown 检查报告。
- `标书评分`：依据招标文件评标办法逐项进行评分检查；用户明确选择后，才进行带不确定性说明的模拟评分。

```text
│   └── AGENTS模板.md
├── 标书spec/
│   └── SKILL.md
├── 标书撰写/
│   └── SKILL.md
├── 标书检查/
│   └── SKILL.md
├── 标书评分/

```

每个技能目录以 `SKILL.md` 为入口；`AGENTS模板.md` 是建档技能创建项目档案时使用的配套模板。

## 使用约定

1. 先用 `招标项目建档` 确认项目、招标文件和参考材料。
2. 用 `标书spec` 固定内容边界、评分点、门槛条款和计划落点。
3. 用 `标书撰写` 生成投标项目目录下的 Markdown 初稿。
4. 初稿交接条件满足后，由独立检查上下文调用 `标书检查`。
5. `标书评分` 可单独调用，也可由 `标书检查` 调用评分检查分支。

技能运行时的项目档案、初稿和报告放在具体投标项目的 `投标输出/<项目名>/` 中；本仓库只维护技能定义，不存放真实项目运行产物。

## 共同边界

- 以完整招标文件及有效澄清文件为要求和评分依据，不用通用模板替代原文。
- 投标人资质、业绩、人员、参数和承诺只能来自用户确认的事实素材，不补造事实。
- `标书检查` 只读标书，问题必须同时有招标依据和投标文件证据；不可读附件或外部状态列为检查盲区。
- 当前输出重点是 Markdown 内容与检查报告，不包含 Word/PDF 排版、签章、密封、CA、平台上传和最终递交操作。
- 检查报告是辅助核查结果，不承诺“检查通过”即不会被否决或一定中标。

## 维护

技能正文使用中文，固定字段名和必要工具名按运行环境保留。修改技能时优先复用现有交接契约和术语，避免把项目管理、递交操作或未经验证的自动化规则加入技能链。
